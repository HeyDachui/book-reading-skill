# 书籍研读技能包

作者：HeyDachui · 技能包版本：1.0.0 · 研读方法：协议 V3

## 这是什么

这是一包给AI看的研读规则。把它和你想读的书交给AI，它会先核对书籍、检查能否读全，再按协议整理知识、标清依据，并交回研读成果。

面向从锤哥号短视频来下载的读者。无需懂代码，也无需安装软件。本包只含规则和说明，不含书籍、书籍原文或研读成果样例。

## 三步使用

1. 在 ChatGPT 新建一个对话，把下载的**技能包ZIP**拖进对话框并发送。
2. 再上传你想研读的**书籍PDF或包含书籍的压缩包**。
3. 发送四个字：**开始研读**。

技能包和书籍分开上传即可，不用重新打包。一次对话研读一本书。

DeepSeek等能读取附件的AI对话也可以按同样方式使用。实际能否读全和交回文件，取决于所用模型的附件、解压、页面查看和文件生成功能；缺少能力时，模型应说明卡在哪里，不能假装已经读完。

**从GitHub下载时：** 优先下载单独提供的 `book-reading-skill_v1.0.0.zip`。若拿到的是仓库源码压缩包，确认里面有 `SKILL.md` 和「协议」目录；这两者必须一起保留。通常无需自行解压技能包。

## 大概要多久

请按几十分钟到数小时预留时间，大部头、扫描件或图表密集的书可能更久。这是等待时间参考，不是已验证的速度保证，也不保证固定两小时完成。具体取决于书长、文件质量、模型能力和平台限制；模型应按实际进度与缺口报告状态。

## 会交回来什么

一个结果ZIP，解压后只有两个文件：

- **研读成果_人读版.md**：给你阅读，包含材料情况、实际读到哪里、知识短卡、分歧和未完成事项。可用文本编辑器或支持Markdown的软件打开。
- **研读成果_AI版.json**：给AI继续读取，保存完整知识卡、短卡、逐项依据和阅读记录。你无需手动填写或修改。

完整卡与短卡一一对应。卡片数量取决于书的实际内容，可能为0；结果是待你审阅的候选草稿，不能自动当作已核实或已采用的知识。

## 读不全时会怎么说

只要还有未读、不可读、缺页、处理失败或尚未判断的承重内容，就必须说**「研读未完成」**，并标为 `INCOMPLETE_WITH_VISIBLE_GAP`，说明缺在哪里、为什么、有什么影响。

局部问题不妨碍其余部分时，继续研读能可靠读取的范围，并交回真实部分成果；重大问题使整体失真时，停止受影响材料并说明原因。无法生成规定ZIP时，也必须说明交付未完成。不能用「文件已生成」「OCR完成」或「已看过全部页码」代替读完。

## 适合和不适合的书

适合：内容和页码完整、文字清晰的电子书，尤其是希望梳理概念、观点、方法、案例和证据的非虚构书籍。

扫描书、图文书也可尝试，但模型必须能查看原始页面并核对承重内容；只有OCR文字时，不能假定图表和小字已读全。

不适合直接要求完整研读：缺页或乱码严重、加密打不开、扫描模糊、超出平台处理能力的文件。诗歌、小说、画册可以按协议研读，但知识卡不能替代对原作语言、情节与审美的完整体验。

## 包里有什么

- [SKILL.md](SKILL.md)：模型入口，规定等待、启动条件、执行顺序和交付。
- [人读协议 V3](协议/01_研读协议_人读版_V3.md)：研读方法、证据边界和完成标准。
- [AI技术字段 V3](协议/02_技术字段与交付格式_AI版_V3.md)：两个结果文件的结构与核验门槛。
- [反例库 V3](协议/03_研读反例库_V3.md)：常见失败及对应处理办法。
- [使用许可](使用许可.txt)：个人学习使用范围。

`SKILL.md`和`README.md`保留通用入口文件名，其余文件和目录用中文命名。上传本包后模型读取规则，上传书籍并发送「开始研读」后才开始本次研读。
